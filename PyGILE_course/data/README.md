# Course data

Small files used by the lessons. They are kept tiny so the course works offline.

| File | What it is | Source |
| --- | --- | --- |
| `nepal_peaks.csv` | Nepal's eight peaks above 8,000 m: height, first ascent year, province, approximate summit coordinates (WGS84) | Heights and ascent years are standard published values; coordinates are approximate |
| `practice_rainfall.csv` | Monthly rainfall at six stations | **Made-up practice data.** The station names are labels (Station A–F); the values follow a realistic monsoon pattern but are not measurements |
| `practice_landslides.csv` | 40 landslide records with date, district, location, area and trigger | **Made-up practice data.** Real district names, but the records are invented for exercises |

Real datasets (district boundaries, DEMs, satellite images, a real landslide inventory) arrive in Parts B to D.
